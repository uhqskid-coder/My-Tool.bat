# 🚀 Installation

## 1. Download the project

Download The ZIP On Discord

Or download the ZIP directly from GitHub.

## 2. Install Python

Some features require Python 3.

Check your installation:

```cmd
py --version
```

If Python is installed correctly, you should see something similar to:

```text
Python 3.x.x
```

## 3. Install Python dependencies

For the username OSINT tool:

```cmd
py -m pip install requests
```

## 4. Launch My Tool

Run:

```text
My Tool.bat
```

# 🎨 Customization

The Batch interface is designed to be modified.

You can customize:

- menu entries
- colors
- banners
- page layout
- tool paths
- shortcuts
- Python utilities

For example:

```bat
if /I "%input%"=="15" (
    cd /d "%~dp0files\osint"
    start "Username OSINT" cmd /k py username_osint.py
)
```

This allows you to add your own Python utilities to the menu.
